# Objetivo
Desenvolver uma página web simples utilizando HTML puro, com foco na aplicação correta das principais tags e estruturas do HTML5, consolidando os conhecimentos adquiridos na disciplina.

# Descrição do Trabalho
O tema escolhido pelo grupo foi **"Viagem dos Sonhos"**, apresentando o destino **Madrid**, capital da Espanha, com seus pontos turísticos, dicas de viagem, curiosidades, custos estimados e um formulário para planejamento da viagem.

# Como Executar
1. Faça o clone ou download deste repositório.
2. Abra o arquivo `main.html` diretamente em qualquer navegador (duplo clique ou "Abrir com").
3. Não é necessário nenhum servidor ou instalação adicional, pois o projeto utiliza apenas HTML puro.
